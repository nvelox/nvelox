# Reporting a security problem

Please report a suspected vulnerability in nvelox by email to
**security@ngris.com**, not in a public issue, pull request or discussion.

A report is easiest to act on when it gives:

- the nvelox version (`nvelox -version`) and how you installed it: release
  binary, container image, package, or built from source;
- the part of the configuration involved, with keys, passwords and
  certificates taken out;
- the requests, connections or steps that show the problem, and what
  happened;
- what someone could do with it.

Please keep the details private until a release with the fix is out.
